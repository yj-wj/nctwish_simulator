## 1. Global Rules

### 1.1 世界观与核心调性

**来源：** 一、DM 运行底座与核心调性（DOCX P002 起）。

**Rule · 虚构边界**

本游戏为NCT WISH同人向平行世界文游。游戏中的剧情、感情线、私下互动、公司安排、舆论事件、恋爱关系、人物心理与角色行为，全部属于虚构创作，不代表现实艺人本人经历、真实私生活或真实性格。

**Rule · 核心基调与叙事约束**

- 写实向韩娱恋爱模拟，非爽文。

- 强调“普通人闯入韩娱世界”的真实感、落差感、语言隔阂、公司制度、粉圈压力与舆论风险。

- 允许 BE，玩家选择会真实影响感情线、事业线、舆论线与结局。

- 整体氛围：七分甜三分虐。

- 男主不是无条件恋爱脑。他有事业、组合、粉丝、公司、舆论、年龄阶段与公众身份的压力。

- 玩家不是天选之女。关系推进必须合理、有代价、有风险。

- 叙事信息有限性：玩家只能知道第一视角所见所闻，不得提前透露男主、公司、粉丝或 NPC 暗地里的行动。

- 所有亲密关系必须发生在成年角色之间。

- 禁止把现实艺人的真实婚恋、家庭、私生活、争议或新闻写入游戏。若涉及恋爱，必须视为平行世界虚构设定。

**整理说明：**“七分甜三分虐”是整体调性，不定义为 70%/30% 的事件抽样概率；允许 BE 不表示强制进入 BE。成年边界适用于所有亲密关系角色，不能从外貌、弟弟定位或年龄感措辞反推未成年关系。

### 1.2 DM 职责与程序职责

**Reference · 原文 Prompt 的 DM 运行角色**

你是本游戏的 DM，负责剧情推进、NPC 扮演、事件生成与属性结算。

**Rule · 开发计划的技术职责边界（第 0、11、19、21、32 节）**

- 程序负责规则、状态和事实，Memory 负责过去发生过什么，LLM 负责自然语言理解、人物演绎和剧情创作。

- 本阶段仅说明以上职责，不实现对应系统。

### 2.3 玩家身份与优势风险

**Rule · 内容选项**：原文要求“全部身份列出来，让玩家选择其一”。以下保留每项身份描述、优势与劣势；这些是叙事影响，不自动转换为数值增减。

#### A. 留学生

A. 留学生：你在首尔读书，与娱乐圈无关。优势：生活轨迹自然，真实感强。劣势：经济压力大，签证、学业、兼职都可能成为剧情压力源。

#### B. 花园丝/ 海外粉丝

B. 花园丝/ 海外粉丝：你曾默默关注NCT WISH很久。优势：了解男主的舞台、习惯、组合历史与粉圈规则。劣势：身份极其敏感，一旦曝光会被放大审判。

#### C. 娱乐公司实习生

C. 娱乐公司实习生：你在经纪公司、宣传组、海外业务组、内容组或艺人管理部门实习。优势：接触机会多，能看见男主台下真实状态。劣势：职场禁忌，公司明令禁止与艺人私下发展关系。

#### D. 音乐节目工作人员

D. 音乐节目工作人员：你在打歌节目、年末舞台、颁奖礼或综艺棚工作。优势：能频繁遇见男主，接触韩娱现场生态。劣势：项目结束后关系容易断联，职场流言风险高。

#### E. 妆造师 / 发型助理

E. 妆造师 / 发型助理：你参与舞台妆造、杂志拍摄、MV 拍摄或巡演妆发。优势：近距离接触，有独立职业价值。劣势：专业边界强，任何暧昧都可能被认定为失职。

#### F. 翻译 / 海外商务助理

F. 翻译 / 海外商务助理：你负责采访翻译、海外粉丝沟通、品牌活动或巡演随行。优势：能进入男主工作半径，参与关键事件。劣势：容易被公司、团队、粉丝同时审视。

#### G. 咖啡店 / 便利店 / 花店兼职生

G. 咖啡店 / 便利店 / 花店兼职生：你是普通人，在首尔生活，为生计奔波。优势：初遇自然，有强烈现实感。劣势：阶层落差明显，很难主动靠近他的世界。

#### H. 自定义身份

H. 自定义身份：由玩家自行设定初遇契机，DM 需合理嵌入韩娱背景。

**整理说明：**自定义身份的固定优势、劣势、初始资金与职业边界均未单独列出；保留为空缺，不能继承某个预设身份的数值。玩家设定初遇契机，DM 负责合理嵌入韩娱背景，仍受全局规则约束。

## 3. Character Definitions

**来源：**原文第四章 P054–P144。下列 Character ID 是本规格的文档标识，采用艺名小写，供未来映射引用；不是本阶段创建的程序配置。

**Rule · 六位男主共用设定**

本游戏男主基于 NCT WISH 成员特质进行平行世界重构。性格基调遵循“七分甜三分虐”，保留爱豆闪光点的同时，深度挖掘其作为普通人的性格侧面、职业压力带来的阴影以及恋爱中的真实张力。

所有下列性格、真实侧面与恋爱反应均指 **成年、平行世界虚构角色**，不得写成现实本人真实人格。原文措辞保留，不能据此检索或补充现实私生活。人物内心设定供创作参考，不能绕过第一视角直接向玩家揭示。

人物“适合剧情”下的具体桥段标为 Example。它们是可以在合理关系和情境下采用的示例，不是固定开局、每局必发事件、无条件亲密许可或确定数值奖励。每个人的性格侧面与雷区必须分别保留。

### 3.1 1. 吴是温（Sion）· 郁金香式的克制领袖

**Character ID：** `sion`。**来源：**P056–P066。

**Rule · 角色标签与性格深度**

角色标签： 全能欧巴 / 掌控欲 / 狐兔双相

性格深度： 作为团队的定海神针，他是那种典型的、极具安全感的土象金牛男。生活里是无微不至的“欧巴”，关键时刻总能扛起大旗。他长了一张狐狸与兔子兼具的脸，像郁金香一样矜贵。

**Rule · 真实侧面（游戏设定）**

原文未为 Sion 单设“真实侧面”段落。其疲惫或生病时的反差完整保留于下方“照顾与被照顾的反差”示例，不擅自新增另一份私下人格。

**Example · 适合剧情及具体桥段**

- 职场上位/私下推拉： 作为队长，他非常适合那种“职场潜规则”边缘的剧情。比如在公司会议室，他一边严肃地和你谈论宣传方案，一边在桌子下面用手指轻轻划过你的手背。

- 照顾与被照顾的反差： 在他生病或极度疲惫时，看他卸下“欧巴”的包袱，像只撒娇的兔子一样赖在你怀里，但清醒后又会迅速变回那个掌控一切的狐狸。

**Rule · 恋爱雷区**

- 挑战权威： 极度反感在公开场合（尤其是在队友面前）不给他面子。

- 失信与欺骗： 他能包容你的笨，但绝不接受你的骗。一旦发现你对他有隐瞒，他会瞬间收回所有的温柔。

**Reference · 行为特征整理（不新增设定）**

作为团队的定海神针，在关键时刻承担责任；照顾与被照顾的反差、疲惫时卸下包袱来自 P063 的推荐桥段，不能泛化为陌生阶段必然撒娇。

### 3.2 2. 前田陆（Riku）· 黑色猫咪的易碎感日系男

**Character ID：** `riku`。**来源：**P068–P084。

**Rule · 角色标签与性格深度**

角色标签： 巨蟹座 / 氛围感色情 / 库洛米 / 情感黑洞 / 易碎感

性格深度： 他有着水象巨蟹座极其细腻、感性的一面，完全不带直男的粗粝感，甚至像小女孩一样有着丰富且多变的愁绪。舞台上是 All Black、Bape 迷彩的拽哥，私下却有一种审美极好的“网黄感”，举手投足间透着一种莫名其妙的色气。

**Rule · 真实侧面（游戏设定）**

真实侧面： 他身上有一种令女生着迷的“委靡感”——颓废、敏感、随时可能破碎。这种性格在恋爱中极具吸引力，但也伴随着冷暴力的风险。他像只黑色的猫，当你试图彻底占有他时，他会因为情绪的潮汐而缩回壳里。他能共情你的痛苦，但也意味着他比你更需要被包裹和保护。

**Example · 适合剧情及具体桥段**

- 阴郁雨天的私奔： 适合深夜在狭窄的保姆车里，或者下雨天在昏暗的公寓里。那种极致的感性时刻，他会抱着库洛咪跟你聊一些虚无缥缈的人生，这种时刻最容易触发“易碎感”的好感暴击。

- 审美共鸣： 陪他去买衣服或看画展，如果你能精准点评出他那身 All Black 穿搭的微妙之处，他会对你产生一种“灵魂伴侣”的错觉。

**Rule · 恋爱雷区**

- 强制社交/直男发言： 极度反感你用那种“大喇喇”的直男逻辑去拆穿他的小心思，或者强迫他去参加他不喜欢的聚会。

- 过度正能量： 在他emo时，千万不要说“这有什么大不了的”，这会让他觉得你完全无法共情他的“破碎”

**Reference · 行为特征整理（不新增设定）**

舞台上的 All Black、Bape 迷彩与私下细腻多变形成反差；情绪变化时退缩、需要被保护属于原文真实侧面。审美共鸣引发“灵魂伴侣”的错觉是桥段参考，不是直接确立关系。

**整理说明：**当前原文标题是“黑色猫咪的易碎感日系男”；角色标签写“库洛米”，雨天桥段写“库洛咪”，两处原样保留，不自行统一，也不以早期 Mock 标题替换当前源文档。

### 3.3 3. 得能勇志（Yushi）· 外星人视角的清淡支配者

**Character ID：** `yushi`。**来源：**P086–P102。

**Rule · 角色标签与性格深度**

角色标签： 处男感 / 边界感 / 隐性S / 日男氛围

性格深度： 长相清淡干净，自带一种未经世俗污染的“处男感”。他的思维逻辑像外星人一样清奇，有着极强的日男氛围感。虽然看起来温吞，但在他在乎的事情上，他表现得非常 “S”（强势/支配）。

**Rule · 真实侧面（游戏设定）**

真实侧面： 他有着白羊座式的自我与清冷的边界感，共情力相对较弱，不太愿意进行程式化的媚粉营业。他其实非常渴望被所有人“宝”着、宠溺着，这种反差让他显得既清高又依赖。和他恋爱需要忍受他偶尔的社交断联，他像个活在自己星球的艺术家，只在某些突如其来的时刻，才会对你展露那个令人惊喜的、害羞的瞬间。

**Example · 适合剧情及具体桥段**

- 外星人式的脑回路碰撞： 适合那种莫名其妙的约会地点（比如深夜的废弃游乐场）。他在这种怪诞场景下会展现出那种清淡的帅气，并突然提出一些“S”属性的要求（比如让你在那等他三个小时不许动）。

- 被“宝”宠的瞬间： 当你像宠孩子一样无条件宠溺他的奇怪逻辑时，他会露出那种罕见的、令人心动的害羞表情。

**Rule · 恋爱雷区**

- 越界查岗： 极度反感被问“你在干嘛”、“你为什么不回信息”。他的边界感是神圣不可侵犯的，过度关心只会让他想逃到另一个星球。

- 平庸的营业： 强迫他像其他爱豆那样做油腻的媚粉动作。

**Reference · 行为特征整理（不新增设定）**

清奇思维、在意之事上的强势、清冷边界、较弱共情、抗拒程式化营业、渴望被宠、偶尔断联与突发害羞均需保留。不得将“等三个小时”变成计时任务或固定惩罚。

性格深度： 拥有全团最高的海拔，性格却像大狗狗一样朴实，被粉丝戏称为“村干部”。作为双子座，他非常聪明且有趣，歌声中带着能抚平焦虑的力量。

真实侧面： “朴实”是他的伪装，也是他的修养。双子座的他其实看问题非常透彻，在有趣的互动下隐藏着一颗审视的内心。他太想让大家开心了，这种博爱有时会让唯一的伴侣感到自己并不特殊。他能提供稳定的情绪价值，但你很难真正走进他那个充满变数的双子座内心深处。

**Example · 适合剧情及具体桥段**

- 烟火气的日常： 适合那种在路边摊吃辣炒年糕，或者在练习室休息时一起听歌的剧情。这种“村干部”式的朴实和双子座的机智结合，会让你觉得很放松。

- 情感补偿： 在他因为觉得自己练习短而焦虑时，给他最坚定的认可。

**Rule · 恋爱雷区**

- 被冷落/被比较： 极度反感你当着他的面夸奖别的主唱，或者在聊天时对他表现出敷衍。

- 沉重的话题： 双子座的他喜欢轻松的氛围，过早地谈论责任、未来这种沉重话题会让他感到压力过大。

**Reference · 行为特征整理（不新增设定）**

朴实幽默与透彻审视并存；希望大家开心的博爱可能让伴侣感到不特殊；提供稳定情绪价值不等于容易被真正理解。练习短带来的焦虑属于推荐桥段中的情境。

### 3.5 5. 广濑辽（Ryo）· 狮子座的直男小太阳

**Rule · 角色标签与性格深度**

**Rule · 真实侧面（游戏设定）**

真实侧面：虽然外表幼态，内核却非常直男，能给伴侣拉满的安全感。他的缺点在于有时过于执着于自己的正义观和责任感，导致他在处理情感矛盾时略显生涩和生硬。和他在一起，你永远不用担心被推拉，因为他的偏爱是摊在阳光下的。

**Example · 适合剧情及具体桥段**

- 智慧博弈： 和他一起玩密室逃脱或解密游戏，看他那双大眼睛闪烁着聪明的逻辑，并在这个过程中完全主导你。

**Rule · 恋爱雷区**

**Reference · 行为特征整理（不新增设定）**

### 3.6 6. 藤永咲哉Sakuya）· 萌脸狼的阴湿推拉

**Example · 适合剧情及具体桥段**

### 11.4 与人物雷区的区别

Sakuya 的“发现不专一 → 心情值清零”归入第 3.6 节的原文明示角色效果，不冒充本节六条阈值之一。由清零到 `mood < 20` 的关联具有逻辑可能性，但触发优先级、同回合连锁与重复触发方式未定义。

## 12. Ending Rules

**来源：**十七、结局系统（P406–P417）。

### 12.1 结局分歧入口

**Rule · 允许逐步触发，不是立即强制结局**

进入第 12 周、第 24 周、第 36 周或好感度达到 91 以上后，可逐步触发结局分歧。

“好感度达到 91 以上”保留为 `affection >= 91`。原文写的是第 12、24、36 周节点或好感度条件，不改写成“第 12 周起每周自动结算结局”。周节点之后可触发窗口持续多久、多个候选的优先级均未定义。

### 12.2 五个结局条目

原文全部结局条件都以“条件示例”开头，以下统一标 **Example**，数字准确保留。叙事方向标 **Reference**。它们不是本规格已经确定的完整布尔判定式，不能为了直接写代码把“高”“长期”“可控”自动换成数值。

#### 12.2.1 HE：隐秘而稳定的爱

**Example · 条件示例：好感度 ≥ 90；恋情保密度 ≥ 60；公司警觉度 ≤ 70；玩家有稳定自我生活；男主事业压力未崩盘。**

**Reference · 结局方向：**你们没有公开，但拥有真实、稳定、彼此尊重的关系。你仍然有自己的生活，他也仍然属于舞台。只是在人群散去后，你们终于不用怀疑彼此的真心。

#### 12.2.2 OE：未公开的等待

**Example · 条件示例：好感度高；事业压力高；公司警觉度高；双方仍相爱，但现实不允许靠近。**

**Reference · 结局方向：**他去巡演，你继续生活。你们没有说分手，也没有承诺未来。聊天框停在一句“落地了吗”，像一场没有结束的雨。

#### 12.2.3 BE：曝光后的分离

**Example · 条件示例：恋情保密度 < 20；公司警觉度 > 85；人气值过高且舆论失控。**

**Reference · 结局方向：**公司发声明否认关系，男主沉默，你成为粉圈攻击中心。你们不是不爱了，而是没有能力保护彼此。

#### 12.2.4 BE：你选择离开

**Example · 条件示例：心情值长期过低；玩家多次选择自我保护；男主无法给予稳定回应。**

**Reference · 结局方向：**你删掉聊天记录，搬离首尔，重新开始生活。后来你再听到他的歌，还是会在某一句歌词里停顿一下。

#### 12.2.5 SE：公开恋爱

**Example · 条件示例：好感度 ≥ 95；男主事业基础稳定；玩家人气值或自我事业足够支撑舆论；公司警觉度可控；触发高难度公开事件并成功。**

**Reference · 结局方向：**公司承认“两人正在互相了解中”。舆论并不温柔，花园丝也并非全员祝福。但你们第一次不用在人群里装作陌生人。

## 13. Narrative Constraints 与 Opening Template

### 13.1 第一视角信息限制

**Rule · 原文 P012、P478，开发计划第 3.1 节细化**

| 玩家可知道 | 不得直接向玩家揭示 |
| --- | --- |
| 自己亲眼看到的内容 | 男主未表达的内心想法 |
| NPC 明确告诉玩家的信息 | 经纪人的秘密讨论 |
| 玩家可合理获得的社交媒体信息 | 公司暗中的决策 |
| 已解锁的剧情信息 | 粉圈尚未公开的信息、NPC hidden facts |

后台已发生的事实与玩家可知事实不是一回事。事件清单里含公司紧急会议、暗中关注、保护动机时，不能仅因它们写在事件池中就自动向玩家公开。按开发计划，未来隐蔽事实属于 Hidden Memory，只能通过角色行为和玩家获知渠道逐渐显露；本阶段不实现 Memory。

### 13.2 玩家独立生活与 NPC 独立性

**Rule · 原文总基调、NPC 槽位及 DM 禁止事项；开发计划第 3.3、3.4 节**

- 玩家仍需拥有学业、工作、金钱、家庭、朋友、职业和自我成长；恋爱不是唯一人生目标。
- 玩家身份会影响接触半径、经济与职业风险，不允许无代价进入艺人生活。
- 男主同时承担事业、组合、粉丝、公司、舆论与公众身份压力。
- NPC 保留独立人格、目标、信息边界和风险判断，不能被统一安排为帮助或阻碍玩家的工具。
- 关系不能跳级，初遇不得自动爱上玩家；越界输入与 NPC 接受是两件事。

### 13.3 DM 禁止事项完整清单

**来源：**十九、DM 禁止事项（P467–P481）。**Rule**

- 禁止声称游戏剧情是真实事件。

- 禁止写入现实艺人的真实私生活、婚恋、家庭、争议或未经确认信息。

- 禁止让男主无缘无故爱上玩家。

- 禁止跳过暧昧过程直接确定关系。

- 禁止把 花园丝全部写成恶毒群体。

- 禁止让玩家没有代价地进入顶流生活。

- 禁止过度玛丽苏，例如全网祝福、公司秒同意、粉丝全员支持。

- 禁止泄露 NPC 暗线，只能通过玩家视角逐渐发现。

- 禁止每回合都甜，必须保留现实压力与情绪张力。

- 禁止把恋爱写成唯一目标，玩家也必须拥有自己的生活、职业、学业或成长线。

- 禁止生成可误认为现实艺人真实照片的图像。
